# GUGU EMPIRE MESSENGER

بات تلگرام و Mini App در **یک Render Web Service**.

## ساختار مخزن
```
bot.py
requirements.txt
render.yaml
miniapp/index.html
```
Start Command: `python bot.py` — متغیر `BOT_TOKEN` را در Render بگذار. مینی‌اپ: `/miniapp`

## مسیر چندمرحله‌ای (جدید)
1. `/admin` ← فهرست پیام‌ها ← پیام استارت ← 🔘 دکمه‌ها ← ➕ دکمه جدید
2. متن دکمه را بفرست (مثلاً «کارت بانکی اختصاصی») و گزینه **🧩 مسیر چندمرحله‌ای** را بزن.
3. مرحله‌ها را اضافه کن:
   - **❓ سوال**: بات می‌پرسد و منتظر جواب می‌ماند (نوع جواب: متن / عدد / شماره کارت ۱۶ رقمی / عکس)
   - **💬 پیام**: خودکار ارسال می‌شود و ادامه می‌دهد
   - **✅ تایید**: پیام + دکمه تایید؛ تا نزند ادامه نمی‌دهد
   - بعد از تایید، هر چند «پیام» بگذاری ارسال می‌شود (متن آخر و ...)
4. پایان مسیر، جواب‌ها به هر دو مدیر می‌رسد (با دکمه ✅ انجام شد) و در تب «درخواست‌ها»ی مینی‌اپ هم ثبت می‌شود.

مثال: سوال «شماره کارت» ← سوال «نام دارنده» ← سوال «عکس فیش» ← تایید ← پیام «ثبت شد» ← پیام «تا ۲۴ ساعت آینده...»

هر دکمه مسیر مخصوص خودش را دارد؛ دکمه «پاسپورت امپراتوری» و «تغییر شماره حساب» هم همین‌طور.
کاربر در هر مرحله می‌تواند «❌ انصراف» بزند یا /start.

در مینی‌اپ می‌توانی مراحل را بسازی، ویرایش کنی، جابه‌جا کنی و درخواست‌ها را ببینی.
(مراحلی که از مینی‌اپ ساخته می‌شوند متن ساده‌اند؛ برای ایموجی ویژه/رسانه، مرحله را از بات بساز.)
