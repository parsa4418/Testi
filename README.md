# بات پیام‌رسان قابل تنظیم تلگرام

## امکانات نسخهٔ اول
- پنل مدیریت فارسی و دکمه‌ای
- تنظیم پیام `/start`
- تعریف چند پیام پشت‌سرهم پس از هر پیام کاربر
- پشتیبانی از متن، عکس، ویدیو، فایل، گیف، استیکر، ویس، ویدیو مسیج، موقعیت مکانی، مخاطب و انواع پیام‌های قابل کپی تلگرام
- مدیریت دکمه‌های شیشه‌ای برای هر پیام
- هر دکمه یک نام مدیریتی، متن نمایشی و عملکرد دارد: ارسال یک پیام یا بازکردن لینک
- ویرایش محتوا، متن/نام/عملکرد دکمه و جابه‌جایی ترتیب پیام‌ها
- ذخیرهٔ تنظیمات در SQLite؛ با ری‌استارت اطلاعات از بین نمی‌رود
- محتوای پیام از خود تلگرام کپی می‌شود تا قالب‌بندی‌هایی مثل Bold، Italic، Spoiler، Monospace، نقل‌قول، لینک‌ها و Custom Emoji تا جای ممکن دست‌نخورده بمانند

## نصب و راه‌اندازی

نیازمندی: Python 3.10 یا جدیدتر.

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در Linux/macOS:

```bash
source .venv/bin/activate
```

فعال‌سازی در Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

نصب کتابخانه‌ها:

```bash
pip install -r requirements.txt
```

فایل `.env.example` را به `.env` تغییر نام بده و مقدار `BOT_TOKEN` را وارد کن. دسترسی ادمین مینی‌اپ فقط برای آیدی‌های `1297047765` و `8904869158` در کد مجاز شده است. برنامه با نصب `python-dotenv` فایل `.env` را خودکار می‌خواند. سپس:

```bash
python bot.py
```

> در هاست‌هایی مثل Render یا VPS می‌توانی متغیرها را مستقیماً در بخش Environment تنظیم کنی و اصلاً فایل `.env` نسازی.

## استفاده
1. مدیر به بات پیام `/start` می‌دهد.
2. از «پیام استارت» محتوای شروع را ثبت می‌کند.
3. از «پیام‌های بعد از دریافت پیام»، پیام اول، دوم، سوم و ... را اضافه می‌کند.
4. برای هر پیام، «مدیریت دکمه‌های شیشه‌ای» را باز می‌کند و دکمه می‌سازد.
5. کاربر با `/start` پیام شروع را می‌گیرد. هر پیام بعدی که برای بات بفرستد، زنجیرهٔ تعریف‌شده را اجرا می‌کند.

## نکته‌های مهم
- بات عمداً برای گفت‌وگوی خصوصی طراحی شده است؛ پیام‌های گروهی را پردازش نمی‌کند.
- بات نمی‌تواند به کاربری که تا به حال خودش بات را Start نکرده پیام خصوصی آغاز کند.
- هر پیام مستقل به‌عنوان یک مرحله ثبت می‌شود؛ برای آلبوم چندعکسی، در نسخهٔ بعدی می‌توان ثبت گروهی آلبوم را اضافه کرد.
- پیام‌های سرویس، رسانهٔ پولی، بعضی نظرسنجی‌ها و Widgetها محدودیت‌های کپی تلگرام را دارند و ممکن است قابل کپی نباشند.
- متن دکمه‌های شیشه‌ای محدودیت تلگرام دارد و حداکثر ۶۴ نویسه است. قالب‌بندی و Custom Emoji مربوط به متن/کپشن پیام است، نه متن معمولی دکمهٔ اینلاین.
- برای اینکه ایموجی‌های سفارشی و قالب‌بندی حفظ شوند، پیام‌ها را از چت مدیر کپی می‌کنیم، نه اینکه متنشان را از نو بسازیم. پیام‌های اصلیِ ثبت‌شده را در چت مدیر حذف نکن؛ بات برای ارسال مجدد به شناسهٔ همان پیام‌ها نیاز دارد.
- فایل SQLite را روی دیسک دائمی هاست نگه دار و از آن نسخهٔ پشتیبان بگیر.

## اجرای پایدار روی هاست
برای VPS از `systemd` یا `screen/tmux` استفاده کن. در Render باید دیسک دائمی متصل کنی و مسیر `DATABASE_PATH` را داخل آن قرار بدهی؛ در غیر این صورت فایل SQLite ممکن است با جایگزینی/ری‌استارت سرویس از دست برود.

## مینی‌اپ مدیریت (نسخهٔ استودیویی)
این پروژه یک Mini App واقعی هم دارد:
- فایل رابط کاربری: `miniapp/index.html`
- از پنل اصلی بات، دکمهٔ «🎨 بازکردن استودیوی طراحی» نمایش داده می‌شود.
- مینی‌اپ با `Telegram.WebApp.initData` احراز هویت می‌کند؛ فقط دو آیدی `1297047765` و `8904869158` به API و استودیوی طراحی دسترسی دارند؛ سایر کاربران پیام «شما اجازه دسترسی به این بخش را ندارید❌» می‌بینند.
- مشاهده پیام‌ها و آمار، مدیریت/افزودن/ویرایش/حذف دکمه‌های شیشه‌ای و جابه‌جایی ترتیب پیام‌های بعدی از داخل مینی‌اپ انجام می‌شود.
- برای ثبت محتوای اصلی (متن، عکس، ویدیو، فایل، ویس و Custom Emoji)، همچنان پیام را در گفت‌وگوی خصوصی بات ثبت کن؛ سپس مینی‌اپ آن را در فهرست نمایش می‌دهد. این کار باعث می‌شود خود تلگرام قالب‌بندی و ایموجی‌های سفارشی را حفظ کند.

### انتشار مینی‌اپ
1. پروژه را روی هاستی با آدرس عمومی HTTPS اجرا کن.
2. در متغیرهای محیطی، `MINI_APP_URL` را برابر آدرس HTTPS همان سرویس قرار بده.
3. پورت را از متغیر `PORT` هاست می‌خواند؛ برای اجرای محلی می‌توانی `WEB_PORT` را تنظیم کنی.
4. در BotFather برای بات، منوی Web App را نیز می‌توانی روی `https://YOUR-DOMAIN/miniapp` تنظیم کنی؛ البته دکمهٔ بازکردن استودیو در پنل `/admin` هم اضافه شده است.
5. پس از نصب وابستگی‌ها و اجرای `python bot.py`، بات با polling و وب‌سرور Mini App در یک پردازش اجرا می‌شوند.

**محدودیت نسخهٔ فعلی:** خود محتوای پیام از محیط چت بات ثبت می‌شود، نه با ویرایشگر متن غنی داخل مینی‌اپ. مینی‌اپ در این نسخه برای مدیریت سناریو و دکمه‌هاست. همچنین دکمهٔ ویرایش عملکرد فعلاً امکان تغییر به لینک را دارد؛ برای ساخت دکمهٔ ارسال پیام، هنگام افزودن دکمه یکی از پیام‌های ذخیره‌شده را انتخاب کن.
