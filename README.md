# GUGU EMPIRE MESSENGER

بات تلگرام و Mini App در **یک Render Web Service** اجرا می‌شوند.

## راه‌اندازی
1. محتوای ZIP را در مخزن GitHub آپلود کن.
2. در Render از New > Web Service مخزن را متصل کن.
3. Runtime: Python؛ Build Command: `pip install -r requirements.txt`؛ Start Command: `python bot.py`.
4. متغیر محیطی `BOT_TOKEN` را در Render اضافه کن. توکن را داخل GitHub نگذار.
5. پس از Deploy آدرس `https://YOUR-SERVICE.onrender.com/miniapp` مینی‌اپ است.

`render.yaml` همین تنظیمات را برای Blueprint تعریف کرده است. دیسک دائمی در این فایل تعریف شده؛ اگر پلن رایگان Render امکان دیسک دائمی ندهد، SQLite پس از ری‌استارت/Deploy ممکن است از بین برود. در آن حالت برای حفظ داده‌ها به دیتابیس خارجی یا پلن دارای Persistent Disk نیاز است.

## امکانات
- /start برای کاربران و /admin برای مدیران
- پیام استارت و پیام‌های زنجیره‌ای با کپی پیام اصلی تلگرام
- پشتیبانی از متن و رسانه‌های قابل کپی تلگرام
- دکمه‌های URL و ارسال پیام ذخیره‌شده
- Mini App برای آمار، ترتیب پیام‌ها و مدیریت دکمه‌ها
- احراز هویت `initData` تلگرام؛ فقط آیدی‌های 1297047765 و 8904869158 مجازند.

## نکته‌ها
- محتوای پیام‌ها را از چت خصوصی بات ثبت کن: `/admin` و سپس گزینه موردنظر.
- پیام اصلی مدیر را حذف نکن؛ بات برای کپی مجدد به آن نیاز دارد.
- Mini App باید از داخل تلگرام و با حساب یکی از دو مدیر باز شود.
- این نسخه از Polling استفاده می‌کند؛ فقط یک نمونه از سرویس را اجرا کن.


## رفع مشکل اجرا در Render
در این نسخه، Polling ربات با `stop_signals=None` اجرا می‌شود تا اجرای آن در ترد پس‌زمینه باعث خطای تنظیم signal در پایتون نشود.
